# SelfconsistentBorn

[![Build Status](https://github.com/vanliggubbe/SelfconsistentBorn.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/vanliggubbe/SelfconsistentBorn.jl/actions/workflows/CI.yml?query=branch%3Amain)

Library for open quantum system simulation using selfconsistent Born approximation based on 
1. [O. Scarlatella and M. Schirò, Self-Consistent Dynamical Maps for Open Quantum Systems, SciPost Physics 16, 26 (2024).](https://doi.org/10.21468/scipostphys.16.1.026)
2. [V. Janković and T. Mančal, Self-Consistent Approach to the Dynamics of Excitation Energy Transfer in Multichromophoric Systems, The Journal of Chemical Physics 161, 204108 (2024).](https://doi.org/10.1063/5.0237483)

Currently in development.
